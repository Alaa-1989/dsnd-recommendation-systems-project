# Project Files

This folder contains the IBM Community recommendation system implementation and supporting files.

- **Recommendations_with_IBM.ipynb** — Completed notebook with analysis, recommendation methods, tests, and findings.
- **Recommendations_with_IBM.html** — Exported notebook with saved outputs and figures.
- **data/user-item-interactions.csv** — User–article interaction dataset.
- **project_tests.py** — Project validation functions.
- **top_5.p, top_10.p, top_20.p** — Reference data used by the validation tests.
- **user_item_matrix.p** — Binary user–article matrix saved from the notebook.
- **requirements.txt** — Python dependencies and their versions.

See the [main README](../README.md) for project details and installation instructions.
